# CEIL: ceiling division by learned constants (pre-registered)

INVENT (docs/INVENT.md) and SELFEDIT (docs/SELFEDIT.md) left "rounded up" answers out of reach:
INVENT's rescaled targets only catch exact division, and SELFEDIT's floor-division fit
(`inv_floor_fit`) produces `v // k`, never `ceil(v / k)`. Both sealed write-ups list the
ceilings among the misses (TRANSFER-4 `g4_crates_needed`; SELFEDIT "the three ceilings").
CEIL is the floor fit's twin for ceilings. Everything is behind **`NOMAD_CEIL`, default OFF**.
No neural nets, no language model; WITNESS certifies every program; the cold control is untouched
(it never reaches the INVENT phase).

## What is built

- `nomad/invent.py`: `ceil_enabled()` (`NOMAD_CEIL`, default off); `Kit.ceil`; `ceil_constants(learned,
  consts)` = the field's learned scales (`bank_scales`) + INVENT's derived constants, `k >= 2` (the
  INVENT round-2 set; genome genes do not reach it). `CEIL_REWIRE` (judge-only control): a seed ->
  the same number of constants drawn (seeded) from 2..12 outside the learned / derived set, built as
  sums of the leaves 2 and 3.
- `nomad/world.py`, INVENT phase only: a block value `v` already computed in the phase (an invented
  block over the inputs, a bank block's probe value, an invented-primitive application) with
  `ceil(v / k)` equal to the goal on every public row, and `v / k` not exact on every row (exact
  division is the rescaled targets' job), is offered as `(v + (k - 1)) // k` =
  `div(add(v, sub(k, 1)), k)` to WITNESS (tag `ceil{k}`). Like the floor fit, the comparison is a
  lookup on a value already paid for; only the WITNESS-gated offer is counted (1 evaluation). An
  empty field has no bank and no constants, so it gains nothing. Switch off: no code path changes.
- Top level only: a ceiling inside a larger formula (`n ceil(a / k)`, `ceil(a / k) + b`) is not
  produced by this fit.

## Pre-registered criteria (committed before any sealed measurement)

All must hold to flip `NOMAD_CEIL` on by default:

1. **CEIL helps**: `trained_on` certifies >= **+3** over `trained_off`, or >= 0 more with >= **25%
   fewer** evaluations (totals over the 23 hard tasks).
2. **The learned constants carry it**: the same bar against the **best of the three rewired
   controls** (most certified, then fewest evaluations).
3. **Gains vanish with an empty field**: `empty_on` equals `empty_off` exactly on every task
   (certified and evaluations).
4. **No sealed task lost**: no task certified by `trained_off` and not by `trained_on`; neither
   `trained_on` nor `empty_on` worse than cold on any task. Every per-task evaluation increase on
   vs off is reported.
5. **Zero per-task losses on every existing sealed suite**, switch on vs off, every arm:
   `SWITCH=NOMAD_CEIL scripts/switch_regress.py` over every judge except `ceil` itself (learning
   deep / science incl. `sci_water_mol` / LOFO; transfer 1-4 and secondary; text; bridge;
   INVENT_TEXT; TRANSFER-5; TRANSFER-6; SELFEDIT2; TEXT_CHAIN; MEANING; INFLECT; LET; TEXT_ABSTRACT;
   ROLES). Gains are allowed and reported.
6. **LOFO total 5,883, worst 1.0x** with the switch on; **the full test suite passes**.

Decision rule: all six pass -> default ON in a separate follow-up commit with the results;
otherwise it stays OFF with an honest write-up here. Nothing under `results/` is overwritten.

**Decision (pre-registered rule): criterion 5 fails, so `NOMAD_CEIL` stays OFF.**

Honest reading. On its own suite the fit does what was claimed, and beats the rewired controls by the
bar. The ROLES trained field is byte-identical with the switch on or off (library, programs,
concepts and lexicon hashes checked after the run), and ROLES `trained_off` / `trained_on` are
unchanged. So the +2 is the search itself. The likely cause, not yet confirmed: in the shuffled arms
the MEANING stage is reached later, after an INVENT phase in which two ceiling offers matched the
public rows and WITNESS rejected them (1 evaluation each, by design). That is the cost the
"1 evaluation per offer" design pays on any task where a computed block happens to round up to the
goal. The existing suites gained nothing: their ceilings divide by constants this field lacks (10, 12,
18, 25, 60), by inputs, or sit inside composites (`n ceil(a / k)`, products of ceilings), which the
top-level fit does not reach.

Best next step for a fair retry, on a new sealed suite: make a rejected ceiling offer free when it is
the same block / constant pair a floor or rescaled lookup already paid for, or gate the offer on a
challenge row read for free from WITNESS's cache, so a miss costs nothing. Then check the ROLES
controls again. Also: the composites (`n ceil(a / k)`, `ceil(a / k) + b`) need ceiling blocks in the
residual table, not only top-level offers.
