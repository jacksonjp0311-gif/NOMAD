# Claim Boundaries — NOMAD v0.6 WITNESS

NOMAD v0.6 demonstrates a bounded architectural separation between transformation search and consequence attestation.

It demonstrates, inside the supplied synthetic benchmark:

- public-only search evidence can be deliberately overfit;
- a separate held-out consequence check can reject that overfit;
- durable skill admission can be gated on context-bound WITNESS receipts rather than a caller-provided success boolean;
- stale receipt replay can be rejected by exact world-epoch matching;
- unsynchronized receipt field mutation can be detected by checksum;
- v0.5 ECHO MAP ranking can reduce search while leaving evidence authority with WITNESS.

It does **not** establish:

- cryptographic authenticity;
- protection from an attacker who can modify WITNESS code or recompute receipt hashes;
- universal truth detection;
- moral judgment or moral neutrality as a scientific property;
- external institutional independence;
- proof of arbitrary software correctness;
- causal understanding of arbitrary environments;
- general intelligence;
- consciousness or subjective witnessing.

The overfit candidate is intentionally adversarial. Stress-mode failure rates are not estimates of real software-repair failure rates.

The term **WITNESS** means an independent software role in NOMAD's evidence architecture, not a claim of consciousness.

## v0.7 CAUSAL SKILLS / CODEWORLD boundary

v0.7 demonstrates conservative applicability learning over a supplied predicate vocabulary and supplied Python edit operators. The CODEWORLD integration uses generated, small, single-module repositories. Successful results should not be generalized to arbitrary real-world repositories, malicious code, unrestricted program synthesis, or general causal discovery.

A promoted `CausalSkill` means only that no witnessed counterexample in the frozen evidence matched its learned conjunction. It is not a proof of causality. Unsupported states should remain eligible for abstention and later experimentation.

---

## v0.8 WORLD MODEL boundary

v0.8 demonstrates learned fault-location ranking over a supplied repository feature language in generated multi-file Python repositories. Module names are shuffled and excluded from learned signatures. Positive location evidence is admitted from WITNESS-supported repairs rather than evaluator fault labels.

The result does **not** establish arbitrary repository comprehension, unique causal localization in systems with multiple valid repairs, unrestricted program synthesis, robustness to malicious code, or a general world model. The repository topology family, candidate edit operators and observable feature vocabulary remain supplied.

The first-rank localization rate is 75%, not 100%. Search preserves alternate hypotheses, which is why final repair correctness can remain 100% inside the benchmark even when the first location hypothesis is wrong.


## v0.9 INQUIRY

INQUIRY tests budget-aware selection of *provided* public module diagnostic contracts. A 64-repository frozen synthetic study recorded 13.37% lower declared weighted query-plus-repair cost than the v0.8 no-query baseline and 64/64 final correctness; all policies were 64/64 correct. The audit independently re-executed 448 query receipts, not the entire coding policy. The experiment shares four fault families across train/test and uses predeclared fractional probe costs rather than measured resources. Neither unrestricted active learning, causal discovery, general programming competence, nor direct BGR-v1.4 runtime integration is established.


### v0.10 GENESIS claim boundary

The demonstrated capability is finite typed AST expression synthesis for two-variable integer tasks with supplied grammar and input/output examples. The original fixed one-edit candidate vocabulary cannot solve the registered tasks; a generic enumerator can. Witness-trained Bitwork context reduces candidate-vector enumeration relative to both global and context-shuffled controls. No test here establishes unrestricted coding, a novel mathematical inference paradigm, real-world repository robustness, adversarially secure WITNESS, energy savings or AGI. Direct BGR v1.4 inference remains unintegrated.
