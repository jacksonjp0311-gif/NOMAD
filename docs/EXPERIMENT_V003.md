# NOMAD v0.3 RESONANCE experiment

## Registered question

Does hierarchical fusion of parser, runtime, traceback, test, AST and deterministic work-proxy evidence improve bounded repair search over a detailed-test-only contextual policy without reducing withheld-challenge correctness?

## Design

Five seeds: 11, 17, 23, 31, 47. Training uses generated single-edit Python tasks only. Evaluation contains 140 fresh single-edit tasks and 120 tasks from six multi-edit compositions. Search sees 10 examples; final assessment uses 13 separate challenge examples. Budgets: depth 4, 180 executed candidates, frontier 512.

Policies: fixed, global learned prior, detailed-test-only contextual, hierarchical RESONANCE fusion.

## Result

Fusion: 140/140 single challenge-correct and 120/120 compound challenge-correct. Mean executed candidates: 1.014 singles and 19.433 compounds. Relative to detailed test-only contextual search, fusion reduced executions 7.19% on singles and 1.40% on compounds. Relative to fixed search, reductions were 90.88% and 49.35% respectively.

## Negative result retained

An earlier exact-key fusion prototype fragmented context and underperformed test-only search on a compound family. The released learner backs full contexts off through error/structure and detailed-test views before global evidence.

## Limits

The benchmark is synthetic and generated by this repository. It is not SWE-bench, Defects4J, an external replication, or evidence of arbitrary Python repair. Runtime nanoseconds are informational only; the cost sensor used for policy context is a deterministic work proxy.
