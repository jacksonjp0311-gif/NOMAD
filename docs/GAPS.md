# Gaps closed

## Query
`nomad/query.py` answers by field readout. A question is hashed to bits. The strongest overlapping domain or learned packet supplies the answer from its receipt. No generation.

## Domain tasks
`nomad/domain_tasks.py` holds integer example families for mathematics, science, language, reasoning, logic, coding, evidence, and meta. Awake selects the family when the bias is a domain packet. Success reinforces that packet.

## Tool selection
`nomad/tools.py` maps domain bias to a measurement tool. The choice is logged on every awake. Tools write to telemetry.

## Held-out difference
A cold start defaults to addition. With domain packets present, readout selects the domain operator and examples. The field carries the difference. Measured on the next awake that overlaps a domain range.

## What remains open
The synthesizer is still bounded integer expressions. Domain tasks are measurable within that bound. Free-form answers beyond packet receipts are not produced. External data collection beyond telemetry is not yet wired.
