# Gaps closed

## Query
`nomad/query.py` answers by field readout. A question is hashed to bits. The strongest overlapping domain or learned packet supplies the answer from its receipt. No generation.

## Domain tasks
`nomad/domain_tasks.py` holds integer example families for mathematics, science, language, reasoning, understanding, problem-solving, logic, coding, evidence, and meta, each with public, challenge, and final splits. The acting domain is the proposer's domain. Certified success may reinforce that packet.

## Tool selection
`nomad/tools.py` maps domain bias to a measurement tool. The choice is logged on every awake. Tools write to telemetry.

## Held-out difference
The frozen `square_product` family is `(x * x) * (y * y)` at `max_eval=2000`, `max_nodes=7`. A cold start misses. A prior trained on WITNESS-backed multiply tasks, never on the held-out rows, finds the program. The live field is reported separately and may not yet show that advantage.

## Twin measurement
Control and treatment run in one pair job. Control is a cold prior. Only a paired certified delta counts as a learning measurement.

## What remains open
The synthesizer is still bounded integer expressions. Domain names are labels on those families, not free-form capability. External data collection beyond optional example files and local telemetry is not yet wired. A live-field held-out win is not claimed until the saved prior itself shows one. Platform isolation and real-repository HOLDs from v0.18 are unchanged.
