# Closed loop

The field affects the next action only when certification and a twin measurement are both present.

- The proposer's domain is the acting domain. A WITNESS-backed success moves `GrammarPrior` order for treatment.
- SIM checks recent history before reinforcing a certified success. Repeated certification failures of the same prediction are skipped.
- The twin scoreboard records treatment-minus-control *certified* success. Control is a cold prior on the same task. Both arms run in one pair job. An unpaired treatment result is pending, not learning.

The packets are no longer only a log. The prior changes synthesis order after WITNESS. The difference is measured only when both arms are present.
