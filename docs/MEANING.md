# MEANING: words grounded in verified structure (pre-registered)

Until now NOMAD knew *what a program does*, never *what a task is about*. MEANING is the
first, testable rung of understanding: NOMAD links the words a task is described with to
the WITNESS-certified program that solved it, so a new task described in words pulls up
the right **concept** before any search starts. "Rug area", "tiles on a floor" and "seats
in a hall" are one idea, rows x columns; the test is whether words learned in one domain
retrieve that idea in another domain with different nouns, input names and distractor
quantities. Everything is behind **`NOMAD_MEANING`, default OFF**. No transformers, no
neural nets, no embeddings: counts, like the rest of the field.

## What is built

- `nomad/meaning.py`
  - **Concept** = a certified program up to variable renaming (`world._canon_vars`, after
    an exact identity simplifier that strips `x+0`, `x*1`, ... padding), with its variable
    types, output type and the SENSE kinds of the tasks it solved.
  - **Lexicon** `prior.lexicon[token][concept]`: how often a task whose description held
    `token` was certified by `concept`. Tokens: lower-cased words (stop words, numbers and
    `{placeholders}` dropped, plural strip) plus adjacent-word bigrams. Relational words
    (`each`, `per`, `every`, `all`) are kept.
  - **Learning** only inside `WorldPrior.add_witnessed` (a verified receipt), only when the
    task carried words, only while the switch is on; decays with the field. The live sleep
    learner (`consolidate.py`) passes `words` when a packet carries them (no live packet does
    today, so the live body is unchanged).
  - **Use** (`stage`, from `world.evaluate(..., words=...)`): concepts scored by
    `sum_t p(concept | t) * idf(t)` over the task's tokens (SENSE kind agreement and use
    count break ties), type-feasible only; the top `MEANING_K = 4` are instantiated over
    the task's inputs by every type-preserving injective renaming (PORT-style, at most
    `MEANING_MAPS = 360`, duplicates up to commutative argument order skipped), each run once
    on the public rows (1 evaluation). A public fit goes to WITNESS (a rejection costs 1
    evaluation, at most 8). The stage spends at most `MEANING_BUDGET = 384` evaluations; on a
    miss the normal search runs **unchanged** on the remaining budget.
  - Empty field: empty lexicon, the stage never runs. Cold control (`prior=None`): never
    reads words. Switch off: nothing learned, nothing read. Final rows never read.
  - `shuffled(prior, seed)`: the control. Same tokens, same counts, same concepts, but each
    lexicon row is re-pointed through a seeded random bijection over concept keys, i.e. words
    randomly reassigned to concepts.
- `nomad/meaning_tasks.py`: 24 integer concepts (rows x cols, volume, perimeter, change,
  equal shares, averages, boxes needed (ceil), two areas, frame (area minus a hole),
  split bill `(a*b+c)//d`, savings `(a-b)*c+d`, weekly pay `(a*b+c)*d`, trips there and back
  `(a+b)*2*c`, painted area `(a*b-c)*d`, ...), each with an independent Python truth.
  **72 training families** (3 per concept; kitchen, garden, school words; inputs
  `tp tq tr tu`, exactly the roles). **34 sealed families** (`SEALED`; stadium, hospital,
  orchestra, airport, zoo, theater; inputs `sa..sf`, shuffled; every story adds one or two
  distractor quantities the answer does not use). Descriptions never contain numbers.
- `scripts/meaning_suite.py` (seed **20261211** (unused by every other suite; TEXT_CHAIN took 20261205), cold at 10,000 / max_size 7 -> easy / hard),
  `scripts/meaning_judge.py` (arms below), `tests/test_meaning.py`.

## Judge (`python3 scripts/meaning_judge.py`, budget 10,000, max_size 7)

Field `trained` = the 16 WORLD families (`variation_probe.train`) + easy science
(`science_probe.train_more`) + the 72 word training families (2 rounds, same loop, receipts
teach the lexicon; training searches never read words, so the field is identical with or
without its lexicon). `words_only` = an empty field trained on the word families only (report).
Arms on the 19 hard tasks, each given its description:
`cold`, `empty_off`, `empty_on`, `trained_off` (NOMAD_MEANING=off), **`trained_on`** (scored),
`shuffled_1..3` (trained field, switch on, `meaning.shuffled(seed 1/2/3)`), `words_only_on` (report).
Easy section: report only.

## Pre-registered criteria (committed before any sealed measurement)

All must hold to flip `NOMAD_MEANING` on by default:

1. **Meaning helps**: `trained_on` certifies >= **+3** over `trained_off`, or >= 0 more with
   >= **25% fewer** evaluations.
2. **Words carry meaning**: the same bar against the **best of the three shuffled-lexicon
   controls** (`trained_on` >= best shuffled + 3, or >= 0 more with >= 25% fewer evaluations).
3. **Gains vanish with an empty field**: `empty_on` equals `empty_off` exactly (certified and
   evaluations); `empty_on - cold` reported.
4. **No sealed task lost**: no task certified by `trained_off` and not by `trained_on`;
   neither `trained_on` nor `empty_on` worse than cold. (A miss may add at most
   `MEANING_BUDGET` evaluations to a task; every such increase is reported.)
5. **Zero per-task losses on every existing sealed suite**, switch on vs off, every arm:
   `scripts/switch_regress.py` with `SWITCH=NOMAD_MEANING` (learning: deep 27 / science 12
   incl. `sci_water_mol` / LOFO; transfer 1-4 (T1 19, T2 32, T3 27-28, T4 18) and the INVENT
   secondary re-runs; text (lang 7, all_sci 10); bridge 13; INVENT_TEXT 13/15; TRANSFER-5 26;
   TRANSFER-6 23 (`graph_judge`); SELFEDIT2 14 (`selfedit_judge --round 2`)). None of these judges passes words, so the expectation is
   byte-identical per-task records; the run verifies it.
6. **LOFO total 5,883, worst 1.0x** with the switch on; **the full test suite passes**.

Decision rule: all six pass -> default ON in a separate follow-up commit with the results;
otherwise it stays OFF with an honest write-up here and the best next step.

## Dev (uncommitted, `/workspace/nomad/meaning_dev`; harbor / museum / bakery words, inputs `da..df`)

Tuning only on these suites: `MEANING_K` 4, budget 256 -> 384 and renamings 120 -> 360 (a
4-role concept over 6 inputs has 360 renamings; at 120 the right one was cut), commutative
dedup, the identity simplifier (variation padding had split one concept into three).
Dev results, 17 hard each (seeds 13 / 17): `trained_on` **17 / 17** vs `trained_off` 13 / 14,
shuffled 13-14 each, empty 0, cold 0; evaluations -99% vs off and vs best shuffled; no task
lost. Expectation for the sealed suite: criteria 1-4 pass with a smaller certified margin
(PORT already reaches many of these concepts at ~5,400+ evaluations after the block-probe
trigger, so much of the gain is cost); concepts the training field never certified (the
frame concept was flaky in dev) are misses that cost up to the stage budget.

Honest framing, written before measuring: this is *retrieval of verified structure by words*
(a learned word -> program association), not language understanding. The descriptions are
templated English written by the same agent that wrote the training texts; relational words
(`each`, `per`, `average`, `there and back`, `left`, `shared equally`) overlap between training
and sealed stories by design, nouns and domains do not. The shuffled-lexicon control is the
test that the words, not the extra retrieval budget, carry the gain.
