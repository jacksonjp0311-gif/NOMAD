# Research Roadmap

## Completed foundations

- **v0.7 — CAUSAL SKILLS / CODEWORLD:** WITNESS-backed skill boundaries and real file/test repair loops.
- **v0.8 — WORLD MODEL:** filename-independent repository graph + failure evidence used to prioritize verified repair locations.

## v0.9 — ACTIVE DIAGNOSIS

Choose repository probes for expected information gain rather than passively accepting existing evidence.

Target loop:

`uncertainty -> diagnostic action -> WITNESS -> posterior update -> repair`.

Primary gate: reduce localization uncertainty and total repair cost against passive WORLD MODEL while preserving final correctness.

## v0.10 — EXTERNAL WITNESS

Move selected verification into a separate process or independently authored evaluator. Compare local WITNESS, process-separated WITNESS and external evaluation.

## v0.11 — OPEN SUBSTRATE

Freeze independently authored adapters and evaluations before learner exposure. Introduce genuinely different transformation families and unseen operators.

## v1.0 — Autonomous Coding Discovery Gate

A frozen external benchmark with unseen repositories, explicit resource accounting, durable witnessed skill transfer, active diagnosis and no benchmark-specific operator injection after freeze.

The target is not a claim of unrestricted intelligence. It is a reproducible demonstration that the same evidence-bounded architecture can perceive, localize, experiment, transform, verify and retain useful knowledge across previously unseen software worlds.


## v0.9 and beyond

- **v0.9 INQUIRY (completed):** budgeted active diagnosis on generated multi-file repositories; independently replayed public probes.
- **v0.10 GENESIS (next):** verified synthesis of previously unavailable AST transformations, tested against unreachable-under-v0.9 cases.
- **v0.11 CAUSAL ATLAS:** predict multi-file side effects and source-of-fault ambiguity.
- **v0.12 MNEMONIC:** durable cross-session skill transfer with controlled forgetting.
- **v0.13 TRANSCEND:** controlled cross-language transfer, with cold-start and shuffled-evidence baselines.
- **v0.14 FRONTIER:** independent real-repository tasks, sandboxed execution and measured total cost.
- **v0.15 RECURSION:** isolated proposals to change NOMAD's own algorithms, WITNESS-gated deployment and rollback.
- **v1.0 AUTONOMOUS CODING INTELLIGENCE:** a target contingent on unseen-repository performance, retained learning, and independently reproducible evaluation—not a version-number proclamation.


### GENESIS checkpoint (v0.10, 2026-11-13)

Typed expression synthesis beyond v0.9's fixed one-edit vocabulary passed a frozen synthetic benchmark. The contextual Bitwork failure-state learner improves candidate search order while WITNESS owns held-back acceptance. The next frontier is generated multi-file software transformations, independently authored tasks, and end-to-end cost accounting, **not** broader intelligence claims.
