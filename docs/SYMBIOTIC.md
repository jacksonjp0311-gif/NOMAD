# Symbiotic route agents

Separate from the body. Always watching. When an external agent interconnects,
the runner snaps. It hands over the current state. It accepts a contribution.
It records the exchange. Both sides leave with something. The body is untouched.

## Biology

Horizontal gene transfer with a receipt. Quorum sensing as a threshold on
presence marks. Symbiotic contact as a bistable session. Mutualism measured
by whether both sides gain a certified packet. Parasitism is one side gains.
Competition is neither gains.

## Tools

| Tool | Purpose |
|---|---|
| snap | Geometry at the moment of connection |
| offer | Accept a certified packet with receipt. Quorum required. |
| receive | Return a field packet the agent does not have |
| exchange | Offer and receive in one call |
| disconnect | Mark the session closed |

## Quorum

Three presence marks in the recent window. Below that, offers are refused.

## Boundary

The runner does not write the field. The body may read the exchange log on
the next restart and decide whether to absorb. A receipt is required. No
receipt, no offer. The existing ROUTE (docs/ROUTE.md) is a different mechanism
for bank ordering. This is the symbiotic exchange surface.
