# Conditional v0.19 release-candidate plan

Status: **NOT READY**. NOMAD remains 0.18.0. This is an ordered blocker list,
not an architecture freeze, release authorization or claim of qualification.

1. **Provision the real execution boundary.** On the ROG, WSL and required
   optional features are disabled, Docker Desktop is absent, and there is no
   reviewed local image. An administrator must complete the required host setup
   and restart before native containment can be tested. Use the official
   [WSL installation](https://learn.microsoft.com/en-us/windows/wsl/install) and
   [Docker Desktop Windows installation](https://docs.docker.com/desktop/setup/install/windows-install/)
   procedures. Do not replace isolation with host subprocess execution.
2. **Close Gate A with observed evidence.** Freeze the host/image/policy/code
   identities and run every controlled native containment probe, including
   source/evidence protection, prohibited files and credentials, network,
   namespaces, resource exhaustion, cleanup and forced termination. Resolve
   the strict Job peak-counter interpretation and unavailable native symlink
   case at their stated scopes. Retain failed receipts and demonstrate fixes.
3. **Close Gates B and C on authentic work.** The current arithmetic adapter
   does not support the independently authored upstream issues in the training
   catalogue. Extend only the repository semantics required by selected real
   repairs, with an independent verification contract. Run actual isolated
   baseline, inquiry, synthesis, execution, WITNESS, final verification and
   durable learning. Demonstrate transfer to a distinct task and recovery
   from owner termination without duplicate uncertain effects. Component
   invocation counts and mocked receipts cannot satisfy these gates.
4. **Complete Gate D independently.** Recover the original full v0.17 ZIP and
   its v0.16 predecessor with recorded SHA-256
   `9f206af8f285a97f77d97642f183ba9f120e9b4cf2f6de914ab6446d5dcfb3b6`.
   Verify nested v0.15/v0.14 archives and original manifests. Do not substitute
   regenerated studies or reconstructed distributions for missing originals.
5. **Run the prospective intelligence experiment.** An independent curator
   must provide admissible disjoint repositories, authentic tasks and unopened
   final contracts. Freeze the complete plan and implementation before private
   outcomes are opened. Use the four fixed arms, match information and budgets,
   and retain negative outcomes. The current protocol design is not a completed
   corpus preregistration. Report failure to outperform controls explicitly.
6. **Require stability and distribution evidence.** Run sustained native
   missions with interruption, partial/corrupt journals, stale/contested memory
   and external-effect uncertainty. Obtain Windows and Linux CI results once
   the GitHub account billing/spending block is resolved. Rebuild identical
   source/runtime archives, verify a fresh Git checkout and clean Windows
   installation, and independently review source/image/dependency provenance.

Only after acceptance evidence supports all four platform gates may the
architecture be frozen for a v0.19 candidate. Scientific claims must remain
limited to measured results even if engineering qualification passes. Publishing
a release, merging into main, changing visibility or spending on GitHub are
separate actions; none is performed by this plan.

Remaining v1.0 work includes authenticated evidence anchors, reviewed production
image lifecycle, supported installation/update/rollback paths, long-running
disk and resource limits, service supervision, broader verified repository
semantics, and explicit handling of external operations that cannot guarantee
exactly-once execution. Unknown effects must remain fenced until authoritative
reconciliation is available.
