# Bitwork weight packets

Sparse binary packets that accumulate learned knowledge.

Each packet is a set of bit positions plus a count. Packets can be split. Overlap is integer intersection size. The fixed readout returns the top packets for a query.

On a WITNESS-supported and final-correct treatment success, the treatment arm appends a packet and may reinforce the acting domain. Control freezes. Public-only success does not grow the field. Packet updates are not a general skill promotion. External or irreversible actions remain separately gated.

No floating-point neural weights. The packets are the geometry.
